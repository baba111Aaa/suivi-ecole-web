# Suivi École - Interface établissement

## Installation (dans GitHub Codespaces)
1. Copier `.env.example` en `.env.local` et y mettre l'URL et la clé publique (anon / publishable) de Supabase.
2. `npm install`
3. `npm run dev`
4. Ouvrir l'aperçu sur le port 3000 et se connecter avec le compte école.

## Ne jamais mettre la clé "service_role" dans ce projet.
